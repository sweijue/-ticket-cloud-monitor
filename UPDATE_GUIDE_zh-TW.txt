V4.0.2 單一通用腳本更新

這版修正：
1. 通用腳本不再每個網站都顯示。只有「管理頁已建立 + 已登記本機」的網址才會出現監控面板。
2. 遠大 Ticket Plus、拓元 Tixcraft、一般網頁共用同一支 universal-linked.user.js，不需要再安裝專屬腳本。
3. 新增「自動／僅本機」監控時，若偵測到新版通用腳本會自動登記；既有監控也可按「登記本機」一次完成。正常情況不用再複製貼上配對碼。
4. 刪除監控後，管理頁會同步清除該網址的本機登記。
5. 沿用 V4.0.1 的 Railway 啟動修正。

GitHub 更新：
- server.js
- public/app.js
- public/index.html
- public/universal-linked.user.js
- public/ticketplus-linked.user.js（舊腳本停用相容層）
- public/tixcraft-linked.user.js（舊腳本停用相容層）

請保留原本 Dockerfile、package.json、public/style.css 與 Railway Volume。

Tampermonkey / Userscripts：
- 只需要保留並更新 Universal Linked Web Monitor 到 V4.0.2。
- 舊 Ticket Plus / Tixcraft 腳本更新到 4.0.2 後會自動變成不執行的相容層；也可以直接停用它們。

使用方式：
1. 在管理頁建立監控；若已安裝 V4.0.2 通用腳本，新增「自動／僅本機」監控會優先自動登記。
2. 舊監控如果以前是用 Ticket Plus／拓元專屬腳本，只要在該筆按一次「登記本機」完成轉移。
3. 管理頁顯示「已自動登記」後，開啟目標網頁。
4. 只有這些已登記的網址會看到「網頁監控」按鈕。其他網站完全不顯示。
